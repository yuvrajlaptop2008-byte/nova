Deploy Nova on Northflank with a one-click template and access it through the web Control UI. This is the easiest "no terminal on the server" path: Northflank runs the gateway for you.

## How to get started

1. Click [Deploy Nova](https://northflank.com/stacks/deploy-nova) to open the template.
2. Create an [account on Northflank](https://app.northflank.com/signup) if you don't already have one.
3. Click **Deploy Nova now**.
4. Set the required environment variable: `NOVA_GATEWAY_TOKEN` (use a strong random value).
5. Click **Deploy stack** to build and run the Nova template.
6. Wait for the deployment to complete, then click **View resources**.
7. Open the Nova service.
8. Open the public Nova URL at `/nova` and connect using the configured shared secret. This template uses `NOVA_GATEWAY_TOKEN` by default; if you replace it with password auth, use that password instead.

## What you get

- Hosted Nova Gateway + Control UI
- Persistent storage via a Northflank Volume (`/data`) so `nova.json`, per-agent `auth-profiles.json`, channel/provider state, sessions, and workspace survive redeploys

## Connect a channel

Use the Control UI at `/nova`, or run `nova onboard` via SSH for channel setup instructions:

- [Telegram](/channels/telegram) (fastest, just a bot token)
