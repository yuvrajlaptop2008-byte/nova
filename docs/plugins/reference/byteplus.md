# BytePlus plugin

Adds BytePlus, BytePlus Plan model provider support to Nova.

## Distribution

- Package: `@nova/byteplus-provider`
- Install route: included in Nova

## Surface

providers: `byteplus`, `byteplus-plan`; contracts: `videoGenerationProviders`
