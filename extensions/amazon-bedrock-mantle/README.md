# Nova Amazon Bedrock Mantle Provider

Official Nova provider plugin for routing Amazon Bedrock Mantle models through OpenAI-compatible provider flows.

Install from Nova:

```bash
nova plugin add @nova/amazon-bedrock-mantle-provider
```

Use this plugin when your Bedrock deployment exposes Mantle-compatible model routing and you want Nova agents to address those models through the Bedrock Mantle provider.
