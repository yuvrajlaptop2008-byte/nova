# Nova Branding

Nova is an independent project. The brand mark is a star ("Nova") on a blue
gradient — no inherited mascot or upstream identity.

## Assets (in `assets/`)

| File               | Use                                                 |
| ------------------ | --------------------------------------------------- |
| `nova-logo.svg`    | Primary app icon / square logo (128×128)            |
| `nova-favicon.svg` | Favicon / small surfaces                            |
| `nova-banner.svg`  | Horizontal lockup with wordmark (README, docs hero) |
| `nova-social.svg`  | Social / OG card (1200×630)                         |

## Colors

- Sky `#8ad7ff` → Blue `#3b82f6` → Deep `#172554` (gradient)
- Star fill `#ffffff` → `#dbeafe`
- Stroke `#0b1220`

## Usage

- Keep the star centered on its gradient tile.
- Wordmark font: system UI / Segoe UI, weight 800.
- Do not reintroduce the upstream lobster mascot or any `openclaw` naming.
